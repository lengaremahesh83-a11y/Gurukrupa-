If the login screen does not proceed, go back to the login page and tap Test Firebase Connection. It will show whether Authentication and Firestore are reachable.

In Firebase Console, open Authentication → Sign-in method → Google and make sure Google is enabled. Also check Authentication → Settings → Authorized domains and add the domain where this HTML app is hosted. Google sign-in normally opens a browser popup, so popups must be allowed for the site.

Your Firebase web config is okay to use in a browser, but your Firestore and Storage rules must require authentication. Do not use public read/write rules for this private business ledger.
